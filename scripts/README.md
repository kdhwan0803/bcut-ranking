# 모델 페이지 갱신

`data.json`의 작품 정보나 공개일을 갱신한 뒤 저장소 루트에서 실행합니다. Node.js의 기본 기능만 사용하며 별도 패키지 설치는 필요 없습니다.

```sh
node scripts/update-model-pages.cjs
node scripts/check-model-pages.cjs
```

생성기는 한국시간의 오늘을 기준으로 공개 작품과 예정작을 구분합니다. 제목, 검색·공유 메타, 소개, FAQ, 구조화 데이터, 작품 목록과 최신작 버튼을 같은 데이터로 생성합니다. 생성된 모델 HTML도 데이터와 함께 `main`에 반영해야 GitHub Pages의 정적 검색 정보가 최신 상태가 됩니다.

날짜 경계 확인이 필요하면 두 명령에 같은 `--date YYYY-MM-DD`를 붙입니다. 미래 날짜로 확인한 뒤 실제 반영 전에는 위 명령을 다시 실행합니다.

브라우저는 매분과 탭 복귀 때 정보를 갱신합니다. 서버의 정적 HTML은 생성기를 실행하여 배포할 때 갱신됩니다. 썸네일 파일 교체는 기존 `img` 필드와 파일 경로를 사용합니다.
